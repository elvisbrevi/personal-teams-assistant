Microsoft: `pta auth microsoft login --no-browser` devuelve URL PKCE; autoriza en el navegador y consulta `pta auth microsoft finish --wait`. Sin `--no-browser` se abre el navegador salvo en modo no interactivo. `cancel` cancela la espera; `logout` detiene el servicio y elimina tokens locales. GitHub: `pta auth github login CLIENT_ID` devuelve código de dispositivo y URL; después usa `pta auth github finish --wait`. Cada espera tiene un máximo de 600 segundos; pendiente es exit 4. Logout local no revoca autorización remota.

`pta github repos` lista el catálogo autorizado. `pta repos clone OWNER/REPO ALIAS` incorpora un checkout gestionado; `sync ALIAS` exige checkout limpio y fast-forward. Repositorios locales se agregan con `repos add ALIAS PATH`, se editan con `edit` y se quitan con `remove`. Quitar conserva archivos y falla si dejaría una fuente dependiente inválida; modifica primero esas fuentes.

`sources add` lee un Resource JSON por stdin, inicialmente deshabilitado, sin audiencias y sin procesamiento externo. `sources edit ID` reemplaza el Resource completo. `sources audience ID` lee un objeto JSON con allowed_conversations, allowed_senders y/o external_processing; el permiso solicitado debe ser explícito. `sources enable ID` habilita esa fuente. Identifica cada tipo y sus límites consultando `sources show ID` y el mapa; las mismas allowlists se aplican a archivos, URLs y herramientas.

`pta self-chat enable [CHAT_ID]` valida la conversación personal contra la cuenta Graph (miembros en chats normales, scope delegado y autores en notas), persiste el límite de activación y conserva audiencias. Sin ID intenta descubrimiento. `self-chat status` muestra configuración y cursor del polling. Autoriza únicamente las fuentes elegidas a la audiencia exacta `chats/CHAT_ID`, conservando audiencias previas. `self-chat disable` aplica la desactivación.

Las salidas del chat personal incluyen un enlace PTA con identificador durable para reconocer una respuesta incluso si Graph pierde el resultado del envío. La prueba requiere una pregunta humana nueva en Teams y auditoría de envío; verificar ausencia de bucles después del reinicio y con un texto humano idéntico a una respuesta anterior. Un fallo de descubrimiento o membresía no autoriza habilitar una excepción global para mensajes propios.

Ante una salida ambigua sin marca recuperable, `self-chat status` lista pending_outputs con nonce y fecha. Tras identificar personalmente su mensaje en Teams/Graph, `pta self-chat reconcile NONCE MESSAGE_ID` registra la correspondencia explícita; valida cuenta, conversación y fecha y no reenvía nada. El agente necesita que la persona identifique esa salida si Graph no conservó la marca.
