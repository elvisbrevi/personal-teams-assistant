Servicio

El chat de prueba funciona sin conectar Teams. Teams requiere una URL HTTPS pública y las credenciales de tu registro Entra.

Credenciales

Las credenciales marcadas como configuradas ya están listas para usar. Sus valores se mantienen ocultos; los campos sirven para reemplazarlas. Las variables de entorno y los archivos de secretos tienen prioridad.

Modelos de lenguaje

Analizan las preguntas y redactan las respuestas. Responde el primero activo; si falla (por ejemplo, sin créditos o con el límite de uso agotado) responde el siguiente. El orden se evalúa de nuevo en cada llamada: el predeterminado vuelve a responder en cuanto recupera su uso. Codex y Claude usan su CLI instalada con su propia sesión; DeepSeek usa su API con DEEPSEEK_API_KEY.

    Proveedores y Teams

    Para un túnel administrado en Cloudflare, activa esta opción, guarda CLOUDFLARE_TUNNEL_TOKEN en Credenciales y deja vacío el archivo local. Su ruta en Cloudflare debe apuntar a la URL y al puerto anteriores. También puedes usar un archivo local con una regla final 404. Si otro supervisor gestiona el túnel, deja ambos desactivados.

    Chat conmigo mismo

    Se procesan mensajes nuevos. Autoriza las fuentes elegidas a la audiencia exacta de este chat. Cada respuesta incluye un enlace PTA para evitar bucles incluso ante un envío ambiguo.

    Migrar esta instalación

    Importa tu config.toml actual. Se conserva su client ID, mapa y directorio SQLite. Importa también las credenciales existentes a este equipo, especialmente STATE_ENCRYPTION_KEY.

    Mensajes recibidos

    Cada mensaje que llega desde Teams, qué decidió el asistente, la respuesta enviada o retenida y el registro de cada paso. Abre un mensaje para ver su detalle.
