        Sources

        Add a source from a repository

        A whole repository is searched by relevance: each answer reads the sections that best match the request, from its Markdown and text files. A new source starts disabled, without audiences and without external processing. The Wiki, Azure DevOps activity, your Teams messages and other tools are added with pta sources add; here you can enable and authorize them.

        Contexts

        A context groups what the assistant knows about one subject, such as billing or a project. When a request names it, by one of its keywords or its name, the answer reads that context's sources among the authorized ones and follows its instructions. A context never authorizes a source.

        Cases

        The kinds of request the assistant tells apart. For each one you can change how the model recognizes it, the extra words that identify it, the sources it reads and how it is answered. The rules on evidence, links and sensitive data always apply. The default texts are in English, the language of the prompts; you can write yours in Spanish. To answer about a subject of your own, add a context.
