    Public URL and tunnel

    The portal operator manages this profile's address and tunnel. Your assistant uses its own Teams callbacks through the same public address.

    Microsoft Graph delivers messages to a public HTTPS URL that must reach the local port. For a tunnel managed in Cloudflare, turn on the option, store CLOUDFLARE_TUNNEL_TOKEN in Credentials and leave the local file empty; you can also use a local file with a final 404 rule. If another supervisor runs the tunnel, leave both off.
