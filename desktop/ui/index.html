      Microsoft Teams y Entra

      Usa tu registro Entra existente (plataforma Mobile and desktop con http://localhost y permisos delegados). El ID de usuario se completa al conectar la cuenta.

      URL pública y túnel

      Microsoft Graph entrega los mensajes en una URL HTTPS pública que debe llegar al puerto local. Para un túnel administrado en Cloudflare, activa la opción, guarda CLOUDFLARE_TUNNEL_TOKEN en Credenciales y deja vacío el archivo local; también puedes usar un archivo local con una regla final 404. Si otro supervisor gestiona el túnel, deja ambos desactivados.
