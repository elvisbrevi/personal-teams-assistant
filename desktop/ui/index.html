      Public URL and tunnel

      The portal operator manages this profile's address and tunnel. Your assistant uses its own Teams callbacks through the same public address.

      Microsoft Graph delivers messages to a public HTTPS URL that must reach the local port. For a tunnel managed in Cloudflare, turn on the option, store CLOUDFLARE_TUNNEL_TOKEN through pta credentials set on this computer and leave the local file empty; you can also use a local file with a final 404 rule. If another supervisor runs the tunnel, leave both off.

      Language models

      They classify messages, write the answers and pick the references they use. The first active one answers; if it fails (for example, out of credits or with its usage limit reached) the next one answers, and the next call starts again with the first. Codex, Claude and OpenCode use their installed CLI with their own login; DeepSeek uses its API with DEEPSEEK_API_KEY.

      The same provider can be added several times with other models or efforts, up to 16 models. OpenCode lists only its favorites: mark them there and detect CLIs again.

        Variables

        Where variables are used

        Each use names the variable it takes; choose another one to point it there. Your agents see only names and versions, and a deleted variable stops working instead of falling back to another credential.

        Local programs

        Programs that receive chosen variables as environment variables of that one process. Your agent or the CLI can propose one; it receives nothing until you approve its program, arguments, folder and variables here. Their output is never shown.

        Delivery destinations

        Other systems that may receive chosen variables. This computer sends the value and your agents only see the result. Nothing is sent until you approve the destination's address, headers, body and variables here; any change needs a new approval.

        Maintenance Advanced

        Erasing removes this account's records and backups from the account store and sets the content key aside; this computer keeps all of its data. Cloudflare keeps a 30-day point-in-time recovery of the store that only its operator can restore and only the set-aside key can read.

        Backups of this computer

        Taken before migrating, promoting and bringing everything back. Restoring one restarts the application, keeps a copy of the current data first and puts the backup back; this computer's link to the account store stays as it is.

Installing it waits for work in progress, replaces the application and pta together, restarts the application and restores the previous version if the new one is not healthy.
